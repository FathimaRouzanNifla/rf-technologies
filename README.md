# RF Technologies Studio

A modern one-page studio website built with React, Vite, TypeScript, and Tailwind CSS.

## Overview

This project presents RF Technologies as a creative technology studio focused on:
- brand strategy
- digital experiences
- UX/UI design
- product and web development
- growth-focused digital systems

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion / Motion
- Lucide React

## Getting Started

### Install dependencies

```bash
npm install
```

### Run in development mode

```bash
npm run dev
```

The site will be available at:

```text
http://localhost:3000
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Project Scripts

```bash
npm run dev     # start Vite dev server
npm run build   # create production bundle
npm run preview # preview built app locally
npm run lint   # run TypeScript check
```

## Notes

- The project uses a custom luxury-tech visual style with gradient accents, monogram branding, and animated layout sections.
- The main layout is structured as a single-page landing site with hero, services, approach, capabilities, and contact sections.
